# Pramod Ubbala

Senior software engineer and systems researcher working on reliable cloud infrastructure, distributed inference, LLM agent systems, and Kubernetes autoscaling.

## Research interests

- Distributed LLM inference and request scheduling
- LLM agent systems and structured tool outputs
- Invariant-preserving context compression
- Kubernetes and KEDA autoscaling
- Heterogeneous event-driven workloads
- Cloud reliability, observability, and performance evaluation

## Research software

- [Invariant-Preserving Compression of Structured Tool Outputs for LLM Agents](https://github.com/upramod/invariant-compression-gate)  
  Reproducibility package with executable invariant checks, benchmark data, result derivations, and automated validation.

- [Semantic Cost-Aware Autoscaling Prototype](https://github.com/upramod/semantic-autoscaling-experiment)  
  KEDA reference implementation for evaluating workload-aware scaling against queue-length baselines.

Both repositories include citation metadata and reproducibility checks.
